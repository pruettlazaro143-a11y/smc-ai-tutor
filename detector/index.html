图层 · Layers
  • 图上每个标注前的数字，对应报告里的条目编号（手机上只显示编号）；鼠标放在 K 线上可以看到它的序号 # 和开高低收，方便逐项核对。
  • 规则：摆动点 = 左右各 N 根的分形；BOS / CHoCH 只认实体收盘越过；清扫 = 影线越过、收盘收回；FVG = A、C 不重叠的那一段，从 B 开始画；OB = 位移前最后一根反向 K 线，只取实体，且必须同时有清扫、FVG、结构突破。完整说明见仓库 references/09-数据识别引擎.md。
  • 强 / 弱：OB 要实体饱满、之后被暴力拉开；FVG 要够宽、伴随结构突破；清扫要真正越过、扫完有反应；结构突破要收盘明显越过、有位移配合。达不到的标"弱"（虚线），报告里写明为什么偏重低、容易失效。
  • 程序不判断诱导、多周期方向、消息面和入场触发，这些要你自己核对。仅供学习，不构成交易建议。

② 数据 · Data

③ 参数 · Settings

N 越大，只认越明显的高低点（结构级别越大）；N 小会把小波动也算进来。

④ 报告 · Report

把报告粘贴给加载了 SMC 教程的 AI，说"按这份识别报告给我讲解"。AI 只负责讲解，不应改动程序识别的位置和价格。
