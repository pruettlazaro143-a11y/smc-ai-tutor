# my-notes · 你自己的 SMC 认知

每个人学 SMC 的来源不同：不同的课程、书、老师，加上自己的实战经验，口径难免有出入。这个文件夹就是留给**你自己的认知**的。

## 放进来之后会发生什么

- **同一概念以你的口径为准**：AI 讲解、出题、复盘都按你的定义来
- **第一次用到时会标注**："这里按你的口径：……；项目默认的说法是：……"，方便你对照
- **只覆盖你写到的部分**：没写到的概念照用项目内容
- **明显风险会提醒**：如果你的口径可能带来明显风险（比如不设止损），AI 会说明理由，但不会强行改掉你的写法

## 三种接入方式

| 你在用 | 怎么做 |
|---|---|
| 任意 AI（上传文件） | 把你的笔记开头加一行 `<!-- my-smc -->`，和 `prompt/SMC-AI-Tutor.md` **一起上传**，发"开始" |
| Claude Skill | 把笔记放进本文件夹（`skills/smc-learning/my-notes/`），开场时会自动读取 |
| 想合并成一个文件 | 按 `_template.md` 的格式写好放进本文件夹，在仓库根目录运行 `python3 tools/build.py`，会生成 `prompt/SMC-AI-Tutor.custom.md`，你的口径已经插在对应章节前面，以后只上传这一个文件 |

格式自由的笔记（比如你已有的蒸馏文件）直接用前两种方式就行；按 `_template.md` 的编号写，合并时能精确放到对应章节。

## 隐私

本文件夹里除了 `README.md` 和 `_template.md`，其他文件默认被 `.gitignore` 忽略，**不会被提交到公开仓库**。想公开分享自己的口径，请自己改 `.gitignore`。
