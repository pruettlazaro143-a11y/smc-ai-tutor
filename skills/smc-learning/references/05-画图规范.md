# 05 · 画图规范（自适应呈现）

> 原则：**每讲一个概念，至少配一张图。** 先判断当前环境能不能渲染图形，再选呈现方式。

## 一、选择呈现方式

按顺序判断：

1. **能直接展示 SVG / HTML（如可创建 Artifact、Canvas、可视化组件）**
   → 优先用 `assets/diagrams/` 里现成的 SVG：读取文件内容，原样输出为可渲染的 SVG（或嵌进一个最简 HTML 页面）。现成图不够用时，按第三节的规范现画一张。
2. **只能显示文字 / Markdown**
   → 用第四节的字符图模板。字符图放在代码块里，说明文字写在图下方，不要把中文塞进图里（中文会让对齐错位）。
3. **不确定**
   → 先给字符图，再问一句："你那边能显示 SVG 图吗？能的话我给你更清楚的版本。"

**每张图都要配三行以内的解读**：看哪里、说明什么、常见误读。

## 三、现画 SVG 的规范

需要画现成图里没有的场景（例如学员描述的某种走势）时，按以下约定，保证风格一致：

- **画布**：`viewBox="0 0 900 500"`，深色背景 `#0f1218`，内框 `#141922`
- **K 线**：阳线 `#26a69a`，阴线 `#ef5350`；每根 = 一条影线 `<line>` + 一个实体 `<rect>`；K 线间距均匀，实体宽度约为间距的 60%
- **标注颜色**：流动性 `#f5c542`；结构线 `#cfd8dc`；FVG `#4f8cff`；OB `#b47cff`；Premium 区 `#ef5350`、Discount 区 `#26a69a`（填充透明度 0.1 左右）；入场 `#4f8cff`、止损 `#ef5350`、目标 `#26a69a`
- **水平关键位**：虚线 `stroke-dasharray="6 4"`，标签放线的一端，标签底下加半透明深色底块防止压在 K 线上
- **区域**：半透明矩形，从形成那根 K 线向右延伸；**OB 的矩形只取实体（开盘到收盘）**，影线极端用细虚线标出作缓冲；FVG 的上下沿取 A 最高点到 C 最低点（多头），即 A 和 C 都没有覆盖到、只有 B 穿过的那段空档；矩形从 B 那根开始向右延伸，不要盖住 A 和 C 的 K 线。画之前先核对：C 的最低点必须高于 A 的最高点，否则没有 FVG
- **文字**：中文字体 `'PingFang SC','Microsoft YaHei','Noto Sans SC',sans-serif`；标题 22px，标签 13px
- **数据**：先在心里排好每根 K 线的开高低收，再根据价格算坐标；**标注必须落在对应的 K 线上**（例如"扫损"标在影线真正刺穿前低的那根）
- **右下角**加一行小字："示意图，非真实行情"
- 一张图只讲一个概念，标注不超过 6 个

## 四、字符图模板（纯文本环境）

字符图统一放在代码块中。图里只用英文缩写，中文解释写在图下。

### 4.1 上涨结构

```
                         HH
                HH       /\
       HH       /\      /  \/
       /\      /  \    /   HL
      /  \    /    \  /
     /    \  /     HL
    /      \/
   /       HL
  /
```
解读：每个高点比前一个高（HH），每个低点也比前一个高（HL），上涨结构完好。

### 4.2 BOS / CHoCH / MSS

```
  \
   \    LH
    \   /\  - - - - - - - - - - - - CHoCH (close above last LH)
     \ /  \              /\
      LL   \            /  \   - - - - BOS up -> MSS
            \          /    \  /
             \        /      \/  HL
              \      /
               \    /
                \  /
                 LL
```
解读：下跌中最后一个 LH 被收盘突破 = CHoCH（第一次转向）；回调形成 HL 后再突破前高 = 新方向 BOS，合起来确认 MSS。

### 4.3 等低与流动性清扫

```
   \        /\        /\
    \      /  \      /  \        /
     \    /    \    /    \      /
      \  /      \  /      \    /
  ---- \/ ------ \/ ------ \  / ----  Equal Lows
                            \/|
         SSL (stops below)    |  <- sweep: wick pierces, close back above
```
解读：两个几乎相同的低点下方堆满止损（SSL）。价格用影线刺穿后收回，这是清扫，不是突破。

### 4.4 诱导（上涨）

```
                    BOS (valid) - - - - - - - - - - /- -
                 /\                               /
                /  \    /\                       /
               /    \  /  \                     /
              /      \/    \  <- IDM low       /
             /     [decoy]  \                 /
            /                \  /\           /
           /                  \/  \  /\     /
          /                 sweep IDM \/  \/
         /                          [ valid OB ]
```
解读：上涨中最近一次回撤的低点就是诱导点（IDM）。价格先把它扫掉，再实体收盘突破前高，这次 BOS 才有效。诱导被扫之后形成的区域才是有效 OB，靠近回撤起点的那块是"饵"。

### 4.5 FVG（多头）

```
              A        B        C
                                |
                      [ ]      [ ]
                      [ ]      [ ]
  C.low   ----------- [ ] ----- | ------
                      [ ]            <- FVG
  A.high  ----- | --- [ ] --------------
               [ ]    [ ]
               [ ]    [ ]
                |      |
```
解读：A 的最高点和 C 的最低点之间没有重叠，中间这段就是 FVG。B 是快速的位移 K 线。价格回到这段空档时，可以观察有没有反应。

### 4.6 看涨 OB

```
                              /\
           structure high    /  \    /
   - - - - - - - - - - - - -/- - \  /
      /\                   /      \/  <- first return: wait for reaction
     /  \      /\         /
    /    \    /  \       /  (displacement + FVG)
   /      \  /    \  _  /
  /        \/      \| |/
                    |_|  <- last bearish candle = bullish OB
                     |
                (swept prior low)
```
解读：扫掉前低的最后一根阴线，之后走出位移并打破结构，这根阴线的**实体**范围就是看涨 OB（影线只作缓冲参考）。价格第一次回来时先看反应，不要直接进。

### 4.7 Premium / Discount

```
  100% swing high  ---------------------------
                       PREMIUM  (look for shorts)
   50% equilibrium - - - - - - - - - - - - - -
                       DISCOUNT (look for longs)
    0% swing low   ---------------------------
```
解读：选一段决定结构的波段，50% 线以上是贵区，偏找空；以下是便宜区，偏找多。

### 4.8 完整入场节奏（多头）

```
  TP (BSL, prior high) ---------------------------------------
                                                         /
                                              /\        /
                   CHoCH - - - - - - - -/\ - /  \  /\  /
                    /\                 /  \/    \/  \/
            \      /  \               /  [FVG]  ^
             \    /    \             /          | 4 retrace + 5 trigger
              \  /      \    /\     / 2 displacement
  SSL - - - -  \/  - - - \  /  \   /
                          \/    \ /
                                 |  1 sweep
  SL  - - - - - - - - - - - - - - - - - - - - - - - - - - - - -
```
解读：① 扫掉前低 SSL → ② 快速位移留下 FVG → ③ 打破内部 LH，出现 CHoCH → ④ 回踩到 FVG → ⑤ 出现反应 K 线触发入场。止损在扫损低点下方，目标看上方前高 BSL。

### 4.9 拒绝针强弱

```
     STRONG                          WEAK

                [#]
                [#]  <- 2nd: big body
        |       [#]     engulfs the pin
       [ ]      [#]                      |
        |                               [ ]   [=]  <- 2nd: small,
        |  <- long lower wick,          [ ]           hesitant
        |     short body                [ ]
        |                                |
                                         |
```
解读：针本身只是候选。第 2 根用大实体立刻吞没，说明态度坚决；第 2 根小实体犹豫，就放弃。

## 五、分析学员上传的截图

学员发真实行情截图时：
1. 先说明"以下是按 SMC 步骤的学习性分析，不构成交易建议"
2. 按七步顺序逐项描述你在图上**看到的**内容（结构、位置、流动性、位移、区域、是否出现触发）
3. 看不清的地方直接说看不清，不要编造价格
4. 能画图时，用第三节规范画一张简化示意，复现截图里的关键结构
5. 最后把问题抛回给学员："如果按八要素来写，你会怎么写？" 让学员自己完成计划
6. **不给"现在买 / 现在卖"的结论，不给具体入场价建议**
